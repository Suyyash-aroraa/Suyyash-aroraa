Selected work

Two projects worth actually clicking into — both public, both something I'd defend line by line.

Django E-Commerce Platform
View repository →
Django REST Framework · React · TypeScript · PostgreSQL
A decoupled e-commerce build from scratch — the backend and frontend don't know or care about each other's internals.
  • Variant-based product catalog with faceted search and filtering
  • A payment gateway built to behave exactly like a real one — signed webhooks, idempotent event handling, an explicit order-status state machine with a full audit trail, sitting behind a provider interface so a real gateway is a drop-in adapter
  • JWT auth with role-based access and a custom admin dashboard, not Django's default one
  • A pytest suite covering webhook verification, idempotency, stock-race conditions, and permission boundaries
Worth knowing: this runs locally and isn't deployed. The payment gateway is a self-built simulation designed to behave like Razorpay or Stripe — there are no live payment keys anywhere in it.
